# Bundled font subsets

`MVJP-Subset.otf` and `MVSC-Subset.otf` are modified subsets of Noto Sans CJK JP / SC Bold, renamed for this project. They include the glyphs used by the checked-in source and captions. Source: https://github.com/googlefonts/noto-cjk . Original copyright and SIL Open Font License 1.1 are in `OFL-and-upstream-notices.txt`.

When adding new lyrics, replace these with full OFL-licensed fonts or regenerate the subsets; otherwise newly introduced glyphs may be missing. Font licenses remain separate from the project MIT license.
